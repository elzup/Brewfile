# Brewfile

Auto backup Brewfile by launchd.

## Installation

```sh
$ curl -sL https://raw.githubusercontent.com/elzup/Brewfile/master/install.sh | sh
```

## Restore

```sh
# Homebrew と npm のグローバルパッケージ (npm "..." 行) をまとめて復元
brew bundle
```

## Backup Schedule

Everyday 06:00
